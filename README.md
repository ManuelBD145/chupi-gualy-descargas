## Gafas Meta Quest

Abre el **Navegador** de las gafas, escribe `manuelbd145.github.io/chupi-gualy-descargas/jugar`, pulsa «🥽 Jugar con gafas VR» y ya estás dentro de Chupicity.

## Instalar el APK en Android

1. Descarga `chupi-gualy.apk` desde el móvil (si el navegador avisa de que el archivo puede ser dañino, pulsa «Descargar de todos modos»).
2. Ábrelo y, si el móvil lo pide, activa «Permitir de esta fuente».
3. Si sale Google Play Protect: «Más detalles» → «Instalar de todos modos» (o «Analizar app»).
4. Si tienes una versión anterior (la 5 o más vieja), desinstálala antes: la app ahora lleva firma propia.

Para no ver nunca el aviso de Play Protect: abre «Jugar ahora» con Chrome y pulsa «📲 Instalar en este dispositivo».

Versión actual: 11.0. Cada versión del APK aparece en [Releases](../../releases) con su huella SHA-256.
